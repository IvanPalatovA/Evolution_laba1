# Лабораторная работа № 1 — вариант 6

Программа ищет минимум пятимерной функции Швефеля генетическим алгоритмом.
Это самостоятельная реализация на Python: готовые пакеты оптимизации не используются.

## Что нужно для запуска

Нужен Python 3.10 или новее. Внешние библиотеки не нужны.

Один запуск с указанным seed:

```bash
python3 main.py --seed 20261001
```

Серия экспериментов из 20 запусков для двух настроек ГА и 20 запусков случайного поиска:

```bash
python3 main.py --experiment
```

После серии команда создаёт или обновляет папку `results`:

- `runs.csv` — результаты каждого запуска и найденные точки;
- `summary.csv` — лучшее, среднее, медиана, стандартное отклонение и худшее значения;
- `trajectory.csv` — минимум, среднее и максимум лучшего значения по поколениям;
- `convergence.svg` — график сходимости;
- `comparison.svg` — сравнение двух настроек ГА и случайного поиска.

В папке уже лежат также PNG-копии двух графиков, чтобы их было удобно открыть без браузера.

## Настройки

Все параметры находятся в [config.json](config.json). `base_ga` — основная конфигурация,
`high_mutation_ga` отличается от неё только вероятностью мутации: 0.40 вместо 0.15.
Для воспроизводимости seeds серии равны 20261001, 20261002, ..., 20261020.

Краткое описание и результаты находятся в [ОТЧЕТ.md](ОТЧЕТ.md).
